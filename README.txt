老人防摔倒与主动报警系统（本地运行示例）

=============================
第一部分：使用说明（先跑起来）
=============================

一、这个项目是做什么的
------------------------
这是一个用于学习和研究的示例项目，目标是：

- 通过摄像头识别老人是否可能发生跌倒
- 通过麦克风识别是否有人呼救
- 在检测到异常时，向手机发送报警提示

特点：
- 完全本地运行，不依赖云服务
- 用于技术学习与实验
- 不是医疗设备，也不能作为安全保障系统


二、运行环境
------------
1. Windows 10 / Windows 11
2. Python 3.10（不建议使用 3.12）
3. USB 摄像头
4. 麦克风


三、第一次运行（一步一步来）
------------------------------
1. 打开本项目文件夹
2. 在空白处按 Shift + 右键
3. 选择“在此处打开 PowerShell 窗口”

依次输入下面三行命令（每行回车）：

python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt


四、配置
--------
1. 进入 config 文件夹
2. 复制 config.example.yaml
3. 重命名为 config.yaml
4. 按文件内说明填写推送信息
   （第一次学习可以先不填）


五、运行程序
------------
在 PowerShell 窗口中输入：

python src/main.py

如果摄像头画面能正常打开，说明程序已成功运行。


=============================
第二部分：学习说明（看懂 & 动手改）
=============================

六、系统整体是怎么工作的（3–5 分钟看懂）
------------------------------------------
程序运行后，会一直循环做三件事：

1. 看画面（摄像头）
2. 听声音（麦克风）
3. 判断是否需要报警

整个系统由 main.py 统一调度，其它模块各司其职。


七、项目结构说明（已标注修改建议）
----------------------------------

src/
 ├─ main.py            ★ 最适合第一次阅读
 ├─ camera.py          △ 不建议一开始修改
 ├─ fall_detect.py     ★ 最适合第一次修改
 ├─ audio_help.py      ★ 可以作为第二步修改
 ├─ alert/
 │   ├─ telegram.py
 │   ├─ wechat.py
 │   └─ sms.py         ★ 适合练习加限制条件
 └─ utils/             △ 可以后续再看

config/
 ├─ config.example.yaml
 └─ config.yaml

models/                △ 不建议修改
requirements.txt       △ 不建议修改
README.txt


八、第一次动手改什么（强烈建议按顺序）
--------------------------------------
1. fall_detect.py：调整阈值、连续判断、打印状态
2. main.py：增加日志、时间戳、状态提示
3. alert/：增加报警冷却时间或新的提示方式


九、暂时不建议修改的部分
------------------------
- models 目录
- requirements.txt
- 摄像头初始化逻辑
- 程序启动和退出流程


十、学习建议
------------
- 先跑起来，再理解
- 每次只改一个小地方
- 改完立刻运行，看变化
- 不要追求一次全懂


十一、说明与边界
----------------
- 本项目仅用于技术学习与实验
- 不作为医疗或安全保障系统
